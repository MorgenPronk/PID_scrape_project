Azure OpenAI · P&ID demo

Extract equipment tags without leaving the browser

Upload one or more text-based PDF P&IDs. The app reads each file, sends the text to Azure OpenAI with your existing prompt, and returns the tags as a tidy list.

Uses `system_prompt.txt` and `examples.txt` from the repo. Azure credentials come from your .env file.
